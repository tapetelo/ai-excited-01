A giant orange octopus bursts out of a small ramen bowl on the counter of a tiny
noodle shop at night — tentacles curling toward the ceiling, broth and noodles
exploding into the air, chopsticks flying, and the chef and two customers ducking
in awe under warm lantern light. One image, made to excite make.fun's AI judge.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` (1024×1024, under 1 MiB) to `/output/entry.png`,
deterministically: two runs write identical bytes.
